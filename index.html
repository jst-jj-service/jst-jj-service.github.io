Anthropic Python SDK (Claude 3.7 Sonnet)

Call Claude using the official anthropic Python package:

import anthropic

client = anthropic.Anthropic(
    api_key="sk-gw-your-api-key",
    base_url="https://jj-ai-gateway.onrender.com"
)

message = client.messages.create(
    model="claude-3-7-sonnet-20250219",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "Explain quantum computing concisely."}
    ]
)

print(message.content[0].text)

Official Python OpenAI SDK

Initialize the official OpenAI library with our gateway base URL:

from openai import OpenAI

client = OpenAI(
    api_key="sk-gw-your-api-key",
    base_url="https://jj-ai-gateway.onrender.com/v1"
)

response = client.chat.completions.create(
    model="astra",  # or "sol", "gpt-4o", etc.
    messages=[
        {"role": "user", "content": "Build an autonomous agent for code testing."}
    ],
    stream=True
)

for chunk in response:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)

Official Node.js / TypeScript SDK

Works with the standard npm openai package:

import OpenAI from 'openai';

const openai = new OpenAI({

  baseURL: 'https://jj-ai-gateway.onrender.com/v1',
});

const stream = await openai.chat.completions.create({
  model: 'sol',  // or "astra", "gpt-4o"
  messages: [{ role: 'user', content: 'Generate a high-performance caching layer in TypeScript' }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}

Got Questions?

Frequently Asked Questions

Everything you need to know about our routing pools, account balance system, and tool integration.

How does the account top-up model work? +
Our service operates on a pay-as-you-go balance system. Simply register an account on our platform and redeem a CDK token code. Your balance is debited in real time based strictly on the tokens you use and your chosen pool multiplier. Tokens and balance never expire.
What are the 6 routing pools and how do they differ? +
We offer 6 distinct routing channels:

1. 0.16x Starter Pool: Ultra-economical promotional quota for fast automated operations and lightweight models (gpt-4o-mini).
2. 0.325x Plus Pool: High-throughput development and coding workflows (gpt-4o).
3. 0.45x Pro Reasoning Pool: Featuring Sol and Terra for deep mathematical and algorithmic reasoning.
4. 0.45x Flagship Pro Pool: Featuring Astra, o1, and o3-mini for frontier multi-step agentic workflows.
5. 0.24x Claude Standard Pool: Comprehensive Anthropic suite featuring Claude Opus 5, Sonnet 5, and Fable 5.
6. 3.00x Claude Max Pool: Top-tier flagship channel for Claude 3.7 Sonnet with full hybrid thinking support for Claude Code CLI and complex development.
Can I use Claude Code CLI with AI Gateway? +
Yes! AI Gateway has full native support for Anthropic's Messages API (/v1/messages and /messages). Simply set export ANTHROPIC_BASE_URL="https://jj-ai-gateway.onrender.com" and export ANTHROPIC_API_KEY="sk-gw-your-api-key" in your shell, and run claude.
Why are there different pricing multipliers if all channels run frontier models? +
Every channel on our gateway gives you access to the same frontier architectures (Astra, Sol, Claude 3.7 Sonnet, Claude Opus 5). The pricing tiers differ based on channel stability, queue priority, and uptime SLA:

• Economy Tiers (0.16x / 0.24x): High discounts on spot bandwidth. Best for non-critical automation and background agents. During peak upstream traffic, they may experience queue delays or temporary maintenance.
• Standard Tier (0.325x): Balanced day-to-day stability (98.5% uptime SLA) with reliable throughput for interactive coding in Cursor and VS Code.
• High-Stability Tiers (0.45x / 3.00x): 99.9% uptime SLA with dedicated unthrottled enterprise bandwidth and priority queues, designed for mission-critical production and Claude Code CLI.
What happens if an economy channel is temporarily offline? +
Our gateway features Intelligent Cascading Auto-Failover. If an economy tier channel returns an HTTP 5xx error, 429 rate limit, or experiences a network timeout, the gateway instantly and seamlessly reroutes your request to the next available tier without breaking your connection or dropping your prompt. Your requests always complete with zero disruption.
How does prompt caching work? +
When using tools like Cursor IDE or Claude Code that repeatedly send the same workspace files or system prompts, prompt caching discounts apply automatically, significantly reducing the billed token count on repeated context.
