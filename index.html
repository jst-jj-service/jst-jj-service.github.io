Configure Cursor IDE in 30 Seconds

Set our gateway as your custom OpenAI provider to empower Cursor with Claude 3.5 Sonnet and GPT-4o:

  1. Open Cursor Settings → Models.
  2. Disable "Use built-in OpenAI API key".
  3. Toggle on OpenAI API Key and paste your API key (e.g. sk-gw-...).
  4. Click Override OpenAI Base URL and enter:
https://api.hzapi.vip/v1

💡 Tip: You can now enable claude-3-5-sonnet-20241022 or gpt-4o in Cursor's model selector!

Official Python OpenAI SDK

Initialize the official OpenAI library with our custom base URL:

from openai import OpenAI

client = OpenAI(
    api_key="sk-gw-your-api-key",
    base_url="https://api.hzapi.vip/v1"
)

response = client.chat.completions.create(
    model="claude-3-5-sonnet-20241022",
    messages=[
        {"role": "user", "content": "Write a high-performance HTTP server in Go"}
    ],
    stream=True
)

for chunk in response:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)

Official Node.js / TypeScript SDK

Works with the standard npm openai package:

import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: 'sk-gw-your-api-key',
  baseURL: 'https://api.hzapi.vip/v1',
});

const stream = await openai.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Explain quantum computing simply' }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}

Are your endpoints 100% compatible with OpenAI SDKs? +
Yes. Both /v1/chat/completions and the new /v1/responses endpoints strictly adhere to standard OpenAI specifications, including streaming (SSE), tool calling / functions, and token usage reports.
Do my purchased token quotas expire? +
No. Tokens redeemed through our CDK card secrets have permanent validity and do not expire. You only consume tokens when you make requests.
How does prompt caching save me money? +
When using models with large repetitive system prompts or source code contexts (like Cursor IDE), cached prompt tokens receive an automatic discount of up to 90%. Your balance is deducted only for the discounted cached token rate.

You can purchase CDK codes directly from our official shop or contact our customer support. Once received, paste the code into your account's "Redeem CDK" page for instant balance crediting.
