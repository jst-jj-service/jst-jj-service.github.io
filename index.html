Configure Cursor IDE in 30 Seconds

Supercharge Cursor with OpenAI o1, o3-mini, and GPT-4o:

  1. Open Cursor Settings → Models.
  2. Disable "Use built-in OpenAI API key".
  3. Toggle on OpenAI API Key and paste your Gateway API key (sk-gw-...).
  4. Click Override OpenAI Base URL and enter:
https://api.hzapi.vip/v1

💡 Tip: Add o1, o3-mini, or gpt-4o in Cursor's model selector!

Official Python OpenAI SDK

Initialize the official OpenAI library with our custom base URL:

from openai import OpenAI

client = OpenAI(
    api_key="sk-gw-your-api-key",
    base_url="https://api.hzapi.vip/v1"
)

response = client.chat.completions.create(
    model="o1",
    messages=[
        {"role": "user", "content": "Build an autonomous agent for code testing."}
    ],
    stream=True
)

for chunk in response:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)

Official Node.js / TypeScript SDK

Works with the standard npm openai package:

import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: 'sk-gw-your-api-key',
  baseURL: 'https://api.hzapi.vip/v1',
});

const stream = await openai.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Generate a high-performance caching layer in TypeScript' }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}

Frequently Asked Questions

Everything you need to know about our OpenAI routing pools and account balance system.

How does the account top-up model work? +
Our service operates on a pay-as-you-go balance system. Simply register an account on our platform and top up your balance. Your balance is debited in real time based strictly on the tokens you use and your chosen pool multiplier. Tokens and balance never expire.
What are the 4 routing pools and how do they differ? +
We offer 4 distinct OpenAI routing pools: 0.21x Starter Pool (for gpt-4o-mini and routine lightweight tasks), 0.32x Plus Pool (for gpt-4o and general coding workflows), 0.50x Pro Pool (for deep reasoning models like o1-mini and o1-preview), and 0.75x Flagship Pool (for official o1 Flagship and o3-mini).
When will Anthropic Claude models be available? +
Claude 3.5 Sonnet, Claude 3.5 Haiku, and Claude Opus integration is currently in testing and will be launched soon. Watch our announcements or check back on the dashboard for updates.
How does prompt caching work? +
When using tools like Cursor IDE that repeatedly send the same workspace files or system prompts, OpenAI prompt caching discounts apply automatically, significantly reducing the billed token count on repeated context.
